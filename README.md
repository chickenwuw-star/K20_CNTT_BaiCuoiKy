# Dự án Web Cá Nhân

Đây là dự án xây dựng trang web giới thiệu bản thân cơ bản sử dụng HTML và CSS thuần.

## Cấu trúc thư mục

* `index.html`: Trang chủ chứa nội dung chính của website.
* `ket-qua.html`: Trang kết quả khi thực hiện gửi lời nhắn ở phần liên hệ trong `index.html`
* `css/style.css`: File định dạng giao diện, bố cục và màu sắc cho trang web.
* `assets/`: Thư mục chứa hình ảnh sử dụng trong bài và ảnh minh chứng quá trình thực hiện (`avatar.png`, `A2_1.png`, `A2_2.png`, `CuoiKy.png`, ảnh chụp màn hình trước và sau khi thêm CSS).
* `docs/`: Thư mục lưu trữ tài liệu báo cáo:
  * `AI_log.md`: Nhật ký ghi lại quá trình tham khảo công cụ AI.
  * `evidence/evidence-index.md`: Danh mục tổng hợp các hình ảnh minh chứng.
* `CHANGELOG.md`: Lịch sử cập nhật các phiên bản của dự án.
