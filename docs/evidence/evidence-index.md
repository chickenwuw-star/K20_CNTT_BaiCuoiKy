# Danh mục minh chứng

Các hình ảnh minh chứng quá trình làm bài lưu trong thư mục `assets/`:

* `MC index chưa có css.png`: Giao diện trang `index.html` ban đầu khi chưa gắn CSS (Update 1).
* `MC index đã có css.png`: Giao diện hoàn chỉnh sau khi áp dụng `style.css` (Update 2).
* `avatar.png`: Ảnh đại diện hiển thị trên trang chủ.
* `A2_1.png`, `A2_2.png`: Ảnh minh họa các phần bài tập đính kèm trên web.
* `CuoiKy.png`: Ảnh minh chứng phần nội dung cuối kỳ trên giao diện chính.
